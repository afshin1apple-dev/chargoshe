
# ربات بازی چهارنفره 🎲

ربات بازی مخصوص چهار بازیکن در دو زوج ثابت.

## دستورهای بازی

- `/join` عضویت در بازی
- `/team 1` انتخاب تیم اول
- `/team 2` انتخاب تیم دوم
- `/status` نمایش وضعیت بازیکنان
- `/begin` شروع بازی
- `/next` کارت تصادفی بعدی
- `/stop` توقف بازی

## دسته‌های کارت

- حقیقت: ۱۲ کارت
- جرئت: ۱۸ کارت
- چالش شخصی: ۱۳ کارت
- چالش زوجی: ۱۰ کارت

## راه‌اندازی

Python 3.10 یا جدیدتر و بسته‌های requirements.txt لازم است.

توکن ربات باید به‌صورت متغیر محیطی BOT_TOKEN تنظیم شود.

توکن را در کد یا مخزن GitHub قرار ندهید.

## قوانین رضایت

اجرای هر کارت با رضایت افراد است و هر بازیکن حق رد کردن کارت را دارد.
